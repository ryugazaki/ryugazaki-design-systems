# job queue monitor for backend teams

See the stuck job before the pager does.

nightshift reads your Redis, SQS, or Postgres queues and prints one honest screen: what is waiting, what is failing, and which worker dropped it. Retry from the same prompt.

[ start free ] [ read the docs ]

# what is on the screen

Five panels. Nothing you have to configure.

queues

Every queue in one table, worst first.

Depth, rate, p95, and failures for each queue, refreshed every second. A stalled queue jumps to the top and its row turns to inverse video so you cannot miss it.

  • > webhooks.out9,812
  •   billing.charge2,140
  •   email.send128

tail

Follow one queue live, with each job's id, attempt, and error on one line.

$ nightshift tail billing.charge

retry

Send failed jobs back in their original order.

$ nightshift retry -n 50

install

9 MB

One static binary. No agent on your workers.

alerts

Pages that name the queue, the error, and the command that fixes it.

13:48:07 [err] webhooks.out stalled. Run: nightshift retry webhooks.out
