Deploy CLI for indie developers

Deploys that don't need a meeting.

Pipeworks takes your repo from git push to a live URL with a passing health check. No YAML, no dashboard archaeology, no standup about why staging is down again.

What you get

Four things, done properly, so you can get back to the app.

Zero-config previews

Every branch gets a URL. You configure nothing.

Push a branch and the link lands in the pull request a minute later. Merge it and the preview cleans itself up.

  • fix-login-redirect.pw.run2 min
  • feat-uploads.pw.run1 h
  • chore-cache.pw.runbuilding

Rollbacks in one command

Broke prod? Type one line.

$ pipeworks rollback

Swaps traffic to the last healthy deploy in under 3 seconds. No rebuild.

Logs you can grep

Plain text. Pipes work.

$ pipeworks logs | grep 500
