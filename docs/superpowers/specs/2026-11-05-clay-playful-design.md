## The clay shadow and rule 7

`_global/anti-slop.md` rule 7 bans large soft shadows on every element. The clay shadow is this system's signature, so it is scoped instead of banned:

- It goes only on things you can press, pick up, or that float: buttons, answer tiles, lesson cards that open, toggle knobs, the toast.
- Panels, text blocks, tables, and the page stay flat.
- The shadow is a token (`shadow-clay`, `shadow-clay-sm`, `shadow-clay-pressed`, `shadow-well`) built from two color tokens (`clay-hi`, `clay-lo`) that change in dark mode. The linter's `shadow-xl` / `shadow-2xl` check is unaffected.

No `allowedGradients` or `allowedOrnaments` are needed.

## Color

- Text and icons on every clay fill (coral, mint, sky, butter) use `on-clay`, a dark plum, in both modes. Secondary buttons sit on `surface` and use `ink`, which flips with the mode.
- `clay-tint` is a light wash for pills and picture wells inside clay fills; it stays light in dark mode so `on-clay` stays readable (11:1 or better).
- Coral as text uses `accent-text`, which reaches AA on `bg` and `surface`.
- Pastels are never text colors. Every color signal has words next to it.
