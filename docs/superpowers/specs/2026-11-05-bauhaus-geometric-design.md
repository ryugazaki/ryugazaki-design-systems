## Color roles

The three primaries are split by job so the "one accent per screen" rule still holds:

- Red is the only action color (primary button, selection, errors). One red button per screen.
- Blue carries information (charts, info badges).
- Yellow is for shapes and section number chips only, never text. In light mode it is 1.45:1 on paper, so it never carries meaning alone.
- Three wood tokens exist only for finish swatches.

All text colors reach WCAG AA on `bg` and `surface` in both modes; text on red, blue, and yellow uses the matching `*-ink` token.

## Exceptions

None. No gradients, no ornaments, no shadows.
